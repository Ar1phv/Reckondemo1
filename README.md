# Reckon

The verified track record for crypto callers.

Log a call before the outcome. It is timestamped and hashed. Get scored automatically. Your record becomes your proof.

## Status

Concept demo. Sample callers and simulated outcomes. Not a live product.

## What the demo shows

1. Log a price based call with a confidence level
2. Lock it with a timestamp and SHA-256 hash
3. Simulate the result and see hit rate and Brier score update
4. See where you rank against sample callers

## v1 scope

1. Price based calls only, resolved from a public price feed
2. Timestamped and hashed entries
3. X login, one profile per handle
4. Onchain anchoring planned for v2

Until anchoring ships, the claim is timestamped and publicly verifiable.

Open `index.html` in a browser. No build step.
